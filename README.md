# EMPHAR

**EMPHAR = Extended Mind Project · Human–Agent Resonance**

心智延伸计划 · 人与智能体共鸣

> 将人的记忆、思考与行动能力延伸到外部。

`emphar` 是为未来合仓准备的统一仓库，计划逐步整合目前分散在几个相关仓库中的能力，构建持续支持记忆、思考与行动的外部系统。

未来统一的命令行入口为 `emp`，取自 **Extended Mind Project**。预期使用方式：

```sh
emp inbox list
emp tui
emp plugin list
emp web
emp memory list
```

当前仅初始化仓库与项目说明；上述命令为规划示例，合仓与功能实现将在后续推进。
